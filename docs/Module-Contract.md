# Vimax Module Contract

Every Vimax organ must:

1. declare its identity and version;
2. expose real capabilities only;
3. declare supported intents;
4. respect Vimax identity and trust decisions;
5. publish state changes as events;
6. support synchronization where the domain requires shared state;
7. preserve negative and positive experience for later iterations;
8. avoid direct dependencies on another organ's internal implementation.
